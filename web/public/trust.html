Set up CatCare notifications

One-time setup per device so CatCare can send you alerts. Takes about two minutes.

Checking this device…
Use Safari. iPhones can only install this from Safari — not Chrome, Firefox, or an app’s built-in browser. If you opened this elsewhere, copy the address into Safari.
1

Download the profile

Tap the button, then tap Allow when Safari asks to download a configuration profile, then Close.

Download profile
2

Install it

Open the Settings app. Near the top you’ll see Profile Downloaded — tap it, then Install (top right), enter your passcode, and tap Install again.

It will say “Not Signed” — that’s expected, it’s your own home server’s certificate.

I don’t see “Profile Downloaded”

Go to Settings → General → VPN & Device Management and look under “Downloaded Profile” for CatCare Local Certificate. If it isn’t there, go back to step 1 and make sure you tapped Allow.

3

Turn trust on

Settings → General → About → scroll to the very bottom → Certificate Trust Settings. Switch on Caddy Local Authority and tap Continue.

This row only appears after step 2 is done — if it’s missing, the profile isn’t installed yet.

4

Add CatCare to your Home Screen

iPhones only allow notifications for apps on the Home Screen. Open the secure address below in Safari, tap Share → Add to Home Screen, then open CatCare from the new icon.

Install it

Open Settings → Security (or Security & privacy) → More security settings → Encryption & credentials → Install a certificate → CA certificate → Install anyway, then pick the file you just downloaded (ca.crt, in Downloads).

Menu names vary a little by phone — searching Settings for “certificate” finds it.

Last step: turn on notifications

On the secure CatCare, go to Settings → Notifications → Push and tap Enable on this device, then Send test notification.
